## Variant: Split Layout Landing

**Status**: ✅ Chosen direction (landing-centered removed by user preference)

### Design stance
Light, airy, editorial. Teal + slate palette. Focus on value proposition before CTA.

### Key choices
- Layout: 50/50 split — left content, right mockup preview
- Typography: Bold headline with accent color, clean body text
- Color: Light bg, teal accent, subtle gradient on mockup side
- Interaction: Clear CTA buttons, feature cards below fold

### Trade-offs
- Strong at: Professional first impression, scannable
- Weak at: Less dramatic than dark variant, less mobile-friendly

### Best for
Users who want to see the product before committing

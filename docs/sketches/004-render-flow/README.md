## Wireframe: Render Flow (Sample → Final)

### Design stance
Step-by-step workflow. Two clear stages — sample (active) and final (locked until sample approved).

### Key choices
- Layout: Two vertical sections, stage 1 active, stage 2 dimmed
- Color: Dark theme (matches studio), amber for future state
- Interaction: Room selector → Generate → Review → Tweak → Unlock Final
- States: Sample active, Final disabled (with reason text)

### What it covers
- Tier 2: Sample render (1 room, pick room, generate, tweak prompt)
- Tier 3: Final render (camera angle checkboxes, all rooms, cost estimate)
- Iteration counter (1/5) for sample tweaks
- "Custom angle" callout

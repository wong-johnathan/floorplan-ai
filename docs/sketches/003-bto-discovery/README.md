## Wireframe: BTO Discovery + Flat Selector

**Status:** ✅ Updated with Edit Layout CTA

### Design stance
Clean, search-driven browse experience. BTO projects as cards with status badges. Flat model selector now offers two paths: default layout or edit floor plan.

### Key choices
- **Layout:** Search + filters at top, project grid below, flat selector pane at bottom
- **Color:** Light theme (user-facing, not admin), teal accent
- **Interaction:** Click project → expands to show flat model selector below
- **States:** Published (teal badge), Coming Soon (amber, dimmed)

### What it covers
- BTO project search + filter
- Project card with location, year, flat types
- "Coming soon" projects with dimmed state
- Flat model selection after clicking a project
- Two CTAs after selecting flat:
  - **[Start Designing]** → skips floor plan editor, uses default layout
  - **[Edit Layout First]** → enters floor plan editor (Screen 4)
- Floor plan preview with room labels
